# docs {944eda}

mdmap reads the markdown docs of a project as one tree an agent walks by id and path instead of opening files, and shows the size of every neighbour before it is opened. These docs are the corpus of mdmap itself, read and written with mdmap.

New here: read by what you need to know; every row opens with `mdmap show <id>`.
